## Summary

Fixes 6 defects filed by the testing team (tko-shield) during TinyTask REST API v1 test development.

## Defects Fixed

### DEFECT-4 (#376) — Priority 8 — HIGH
**Transfer response shape mismatch**
- Changed `moveTask()` to return `{task: ParsedTask, comment: CommentData}` instead of flat `TaskWithRelations`
- Updated `TaskTransferResponseSchema` in response-schemas.ts
- Updated OpenAPI spec to reference `TaskTransferResponse`

### DEFECT-1 (#373) — Priority 7
**Non-numeric priority accepted**
- Added type validation in POST /api/v1/tasks handler — rejects non-number priority with 400

### DEFECT-2 (#374) — Priority 6
**Timestamps not ISO 8601**
- Added `toISO8601()` helper to TaskService, CommentService, LinkService, and QueueService
- All parse methods now convert SQLite `YYYY-MM-DD HH:MM:SS` to `YYYY-MM-DDTHH:MM:SSZ`
- Applied to embedded comments/links in TaskService.get() and moveTask()

### DEFECT-6 (#378) — Priority 6
**queue_name filter ignored**
- Added `queue_name`, `parent_task_id`, and `exclude_subtasks` filter handling to list() method

### DEFECT-5 (#377) — Priority 5
**Queue patch wrong field name returns 500**
- Already fixed in merged PR #11 (validation with optional chaining + type check)
- Added test coverage to confirm proper 400 response

### DEFECT-3 (#375) — Priority 4
**Non-numeric task ID returns 'Task NaN not found'**
- Added NaN check in GET /tasks/:id handler — returns proper error with 400

## Test Coverage
- Added `tests/integration/rest-api-defects.test.ts` with 15+ test cases covering all 6 defects
- Uses supertest against Express REST router with in-memory test databases
